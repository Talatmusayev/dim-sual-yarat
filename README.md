# DİM SualUsta - Müəllimlər üçün DİM Standartında İmtahan və Test Hazırlayıcı

Azərbaycan Respublikası Dövlət İmtahan Mərkəzinin (DİM) buraxılış (9 və 11-ci sinif) və ali məktəblərə qəbul (blok) imtahanları modelinə tam uyğunlaşdırılmış, məktəb müəllimləri üçün nəzərdə tutulmuş müasir imtahan hazırlama platforması.

---

## 🌟 Ən Son Təkmilləşdirmələr

1. **Riyazi Simvolların Ağıllı Görünüşü (Fənn Filtri)**:
   - Riyazi simvollar paneli yalnız **Riyaziyyat** və **Fizika** fənləri seçildikdə görünür.
   - Digər fənlərdə (Azərbaycan dili, Tarix, Biologiya, Kimya, İngilis dili, Coğrafiya) avtomatik gizlədilir.

2. **Fiqurlar Bölməsi İlkin Olaraq Bağlıdır**:
   - Riyaziyyatda və digər fənlərdə həm şəkilsiz (sadə cəbr və mətn sualları), həm də şəkilli suallar asanlıqla yaradılır.
   - Müəllim şəkil qoymaq istədikdə **"📐 Fiqurlar Pəncərəsi"** düyməsinə klikləyir və PowerPoint tipli studiya açılır.

3. **MS Paint / PowerPoint Tipli İnteraktiv Fiqur Studiyası (Vektor Rəsm Kətanı)**:
   - **Təpələrdən Tutub Formanı Dəyişmə (Draggable Vertices)**: Müəllimlər fiqurun (üçbucağın, kvadratın, trapesiyanın) uclarındakı parlaq mavi tutacaqlardan tutub siçanla dartaraq fiquru sərbəst uzada, qısalda, əyə və bucaqlarını dəyişə bilirlər.
   - **Paint Tipli Rəsm Alətləri**:
     - 🖱️ **Seç / Tərpət**: Təpə nöqtələrini və ya çəkilmiş xətləri/yazıları hərəkət etdirmək üçün.
     - 📏 **Xətt (Çubuq)**: Sərbəst hərəkət edən xətt əlavə edir. Uclarından tutub uzada, qısalda, döndərə və ya bütün xətti daşıya bilərsiniz.
     - 📐 **90° Bucaq**: Düz bucaq nişanını istənilən təpəyə və ya küncə yerləşdirə bilərsiniz.
     - 🏹 **Ox Xətti**: İstiqamət və ya vektor göstərmək üçün.
     - 🔤 **Mətn / Yazı Qutusu (Text Bar)**: İstənilən mətni (`h = ?`, `m = ?`, `6 sm`, `α`, `S = 24 sm²` və s.) kətana qutu kimi yerləşdirir. Mətn qutusunun **ortasından tutub istənilən yerə sürüşdürmək**, **4 küncündəki tutacaqlardan tutub ölçüsünü böyüdüb-kiçiltmək** və üzərinə iki dəfə klikləyib mətni dərhal redaktə etmək mümkündür.
     - 🗑️ **Sil və 🧹 Təmizlə**: Seçilmiş xətti və ya bütün əlavələri təmizləmək imkanı.
   - **Rəng və Xətt Seçimləri**: Qara (DİM), Qırmızı, Göy, Yaşıl, Narıncı; Düz xətt, Qırıq-qırıq xətt, Nöqtəli xətt və müxtəlif qalınlıqlar.
   - **Rəsmi DİM Standartında İxrac**: İmtahan vərəqində və PDF/Word fayllarında tutacaqlar gizlədilir, təmiz vektor həndəsi rəsm göstərilir.

4. **Testi Birbaşa Yükləmə (Download)**:
   - 📄 **PDF Formatında Yüklə**: Rəsmi A4 DİM test vərəqi formatında.
   - 📝 **Word (.doc) Formatında Yüklə**: Microsoft Word-də birbaşa açılıb redaktə oluna bilən sənəd.
